# Glossary

This glossary defines key terms used throughout the Intersul platform documentation and user interface.

| Term | Definition |
|------|------------|
| **Client** | A customer or organization that receives copy machine services from the service provider. Clients have profiles containing contact information, service history, and relationship data. |
| **Copy Machine** | A physical device (printer, copier, or multifunction device) that is tracked in the system. Machines can be owned by clients, rented, or available for sale. |
| **Employee** | A user of the Intersul platform who works for the service provider organization. Employees have authentication credentials and can be assigned to service steps. |
| **Franchise** | A business unit or branch within the service provider organization. Used for organizational structure and reporting segmentation. |
| **Invitation** | A secure token-based mechanism for onboarding new users to the platform. Invitations are sent to email addresses and allow users to register and set up their accounts. |
| **Maintenance Service** | A service type focused on repair, upkeep, and preventive maintenance of copy machines. Includes scheduled maintenance and reactive repairs. |
| **Rental Service** | A service type for copy machine rental agreements. Tracks rental periods, machine assignments, and rental-specific workflow steps. |
| **Sale Service** | A service type for copy machine sales transactions. Manages the sales process from quotation to delivery and installation. |
| **Service** | A general term for any work order, transaction, or activity managed in the system. Services can be of different types (maintenance, rental, sale, or supplies) and follow structured workflows. |
| **Service History** | A chronological record of all services performed for a specific client, providing visibility into past interactions and service patterns. |
| **Service Step** | A discrete task or stage within a service workflow. Steps have assigned employees, status tracking, and can include documentation such as images or notes. |
| **Service Type** | A categorization of services based on their nature: maintenance, rental, sale, or supplies. Each type may have different workflow steps and data requirements. |
| **Step Status** | The current state of a service step, indicating whether it is pending, in progress, completed, or blocked. Used to track workflow progress. |
| **Supply** | Inventory items used in copy machine services, including consumables (toner, paper) and parts (components, accessories). Supplies are tracked for inventory management. |
| **Supplies Service** | A service type focused on providing supplies to clients. Manages supply orders, deliveries, and inventory allocation. |
| **User** | An authenticated individual with access to the Intersul platform. Users can be employees, administrators, or other authorized personnel. |
| **Workflow** | A predefined sequence of steps that a service must complete from initiation to closure. Workflows ensure consistent service delivery and accountability. |
